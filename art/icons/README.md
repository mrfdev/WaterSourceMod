# Icon candidates

The project keeps three high-contrast icon candidates for accessibility and
future branding choices:

1. `icon-01-water-drop.png`, a bright blue drop with a gold accent.
2. `icon-02-source-block.png`, the selected default: a blue water cube with a
   bright gold frame and ripple symbol.
3. `icon-03-ripple-marker.png`, a ripple-focused marker treatment.

The selected default is copied to
`src/main/resources/assets/watersourcemod/icon.png`.
