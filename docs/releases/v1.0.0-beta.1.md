# 1MB Water Source v1.0.0 Beta 1

Public Beta 1 publishes the exact build `012` JAR that was user-tested and
confirmed working on Minecraft 26.2.

## Download

- Client JAR: `1MB-WaterSource-v1.0.0-012.jar`
- SHA-256: `34aeb9e0be9b43387a4be4f9299bee6916204552743fd32176c6c8d9d9e762b7`

Do not install this JAR on the server. Install it only in the Fabric client's
`mods/` folder.

## Tested environment

- Minecraft 26.2
- Java 25
- Fabric Loader 0.19.3
- Fabric API 0.154.2+26.2
- Mod Menu 20.0.1 (optional)
- Multiplayer connection to a Paper 26.2 server with no WaterSourceMod
  server-side component

## Beta 1 highlights

- Toggle the overlay with `F9` and force a rescan with `Shift+F9`.
- Open the built-in settings with `F10`, with or without Mod Menu.
- Distinguish source water from flowing water with independent visibility,
  high-contrast colors, and live color previews.
- Configure a 3x3 or larger loaded-chunk scan area, waterlogged sources,
  marker style, opacity, outline thickness, pulse, labels, and marker limit.
- Keep the status HUD at the top center to reduce conflicts with corner HUDs.
- Keep through-wall rendering off by default with a fair-play reminder.
- Match 1MB Locator HUD's key/value and `ON`/`OFF` settings colors.

## Privacy and fair play

The mod is client-only and performs no telemetry, analytics, account tracking,
or network requests. It scans only chunks the server has already sent to the
client. Through-wall visibility is optional and disabled by default; players
remain responsible for following each server's rules.

Report Beta 1 bugs or accessibility feedback through
[GitHub Issues](https://github.com/mrfdev/WaterSourceMod/issues). Include
Minecraft version, Fabric Loader/API versions, mod build `012`, reproduction
steps, and sanitized logs when relevant.
